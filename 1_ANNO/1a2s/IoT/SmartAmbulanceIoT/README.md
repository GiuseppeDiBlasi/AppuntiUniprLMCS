# SmartAmbulanceIoT

## Requirements

- Eclispe IDE
- Compiler compliance level: Java 1.8
- Java openJDK version 21.0.10

## How to run the project

- Import the folder "IoTClass2026_JavaProject" as an existing project inside Eclipse IDE
- Under the package "it.unipr.iotlab.iot2026.cf.sim" right click on the file "SmartAmbulanceSimulation.java"
- The program should be running in the Eclipse terminal
