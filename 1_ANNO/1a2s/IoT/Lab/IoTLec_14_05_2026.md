# CoAP protocol

RESTful application protocol 

low parsing complexity 

it follows the same scheme as HTTP when specifying a URI

message ID and tokens

coap exploits the resource observations

coap supports multicast communication

coap allows for resource discovery, it allows to dynamically discover nodes inside the network.
All the node that support coap also support the resource discovery
