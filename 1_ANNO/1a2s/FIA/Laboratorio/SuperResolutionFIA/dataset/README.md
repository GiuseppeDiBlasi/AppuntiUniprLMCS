# Dataset
You can put your datasets in this folder.

## Sources

We would like to thank [https://data.vision.ee.ethz.ch/cvl/DIV2K/](https://data.vision.ee.ethz.ch/cvl/DIV2K/) for providing the datasets used to train our models.

Here's the full list of the ones we've used:

1. [Train Data Track 1 bicubic downscaling x2 (LR images)](http://data.vision.ee.ethz.ch/cvl/DIV2K/DIV2K_train_LR_bicubic_X2.zip)
2. [Validation Data Track 1 bicubic downscaling x2 (LR images)](http://data.vision.ee.ethz.ch/cvl/DIV2K/DIV2K_valid_LR_bicubic_X2.zip)
3. [Train Data (HR images)](http://data.vision.ee.ethz.ch/cvl/DIV2K/DIV2K_train_HR.zip)
4. [Validation Data (HR images)](http://data.vision.ee.ethz.ch/cvl/DIV2K/DIV2K_valid_HR.zip)
