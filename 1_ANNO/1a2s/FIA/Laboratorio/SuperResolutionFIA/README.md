# Image Super Resolution

A project on image super resolution using deep learning.

**Course**: Fondamenti di Intelligenza Artificiale (FDI)

## Overview

This project aims to develop a deep learning model for image resolution enhancement...

### Prerequisites

- Python 3.8+

## Setup

1. Clone the repo: `git clone https://github.com/GiuseppeDiBlasi/SuperResolutionFIA.git`
2. Move into the directory: `cd SuperResolutionFIA`
3. Create a virtual environment: `python3 -m venv .venv`
4. Activate the virtual environment: `source .venv/bin/activate`
5. Install the dependencies: `pip install -r requirements.txt`
