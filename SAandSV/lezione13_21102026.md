# Speeding up static analysis with Split Operator 

- Filtrare un elemento astratto
- Operatore di split 

----------------------- 

filtro: A x Pred -> A 

Pred: restituisce il risultato booleano della valutazione di un espressione

fuznione filtro, questo operatore permette di modellare il controllo di flusso del programma
restituisce in output l'elemento A filtrato per Pred 

------------------------------- 

split: A x Pred -> A x A 

stesso dominio della fuznione di filtro, in output l'elemento filtrato per Pred e anche il suo complemento.

è un miglioramento rispetto alla funzione di filtro, la funzione di filtro presenta molto overhead.
split evita copie ridondanti che possono verificarsi con l'operatore di filtro.
